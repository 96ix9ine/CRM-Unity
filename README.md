Кратко о проекте:

CRM система версии на Unity, разрабатывалась как дополнение к web версии https://github.com/tr0stals/crm-practice (в дальнейшем разработка велась только над web версией, а разработка на Unity приостановилась, разработка на Unity велась только мной).
Основные возможности:
Управление более чем 15 бизнес-сущностями
Автоматическая генерация производственных задач
Автоматизированный складской учет
Управление технологическими процессами
Иерархическое отображение данных с помощью TreeView
Поиск и пагинация
